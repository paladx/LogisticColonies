# Verwendete Originaldateien

Bereitgestellt: Little Logistics beta.2, BlockUI 1.0.210, Domum Ornamentum 1.0.236,
Multipiston 1.2.58, AE2Colonies 1.2.2 und CreateColony 1.0.0.

Der Anhang für MineColonies überschritt das 32-MiB-Übertragungslimit. Für den Build
wurde die identisch benannte Veröffentlichung 1.1.1403-1.21.1 von CurseForge verwendet:
https://www.curseforge.com/minecraft/mc-mods/minecolonies/files/9058295

Structurize war nicht angehängt und wurde passend zur gepinnten Build-Abhängigkeit ergänzt:
https://www.curseforge.com/minecraft/mc-mods/structurize/files/9017852

NeoForge 21.1.219 / NeoGradle 7.1.38: https://maven.neoforged.net/releases/
Gradle 8.14.3: https://services.gradle.org/distributions/gradle-8.14.3-bin.zip

Fremde JARs werden nur lokal zum Entwickeln verwendet und nicht weiterverteilt.
Der gemeinsame Serverstart wird gesondert im Prüfprotokoll nachgewiesen;
er ersetzt keinen funktionalen Test der jeweiligen Logistiknetze.

Für den zusätzlichen Kompatibilitätsstart wurden Originaldateien aus Modrinth geladen,
mit den SHA-512-Prüfsummen der API geprüft und ausschließlich lokal verwendet:

- Create 6.0.10: https://modrinth.com/mod/create/version/UjX6dr61
- AE2 19.2.18: https://modrinth.com/mod/ae2/version/KDnFUmMm
- GuideME 21.1.22: https://modrinth.com/mod/guideme/version/QeYKsstN

Die beiden vom Nutzer bereitgestellten Integrationsaddons liegen beim Test im
Server-Modordner; sie werden weder neu gepackt noch verändert.
